# Директивы Кодирования (resolve)

Соблюдение правил `AGENTS.md` строго обязательно.

## 1. Контракты и Типизация (Strict Contracts & Zero Any)
- 100% строгая типизация. **Запрет `any` и неявных приведений**.
- Связи модулей → строго через публичный API / контракты слоёв.
- Запрет самовольного изменения / игнорирования утверждённых TS-контрактов.

## 2. Изоляция Модулей и История (Isolation & History)
- Модули/плагины изолированы. **Запрет deep-импортов** внутренних файлов из чужих модулей/слоев/плагинов.
- Интеграция → строго через `index.ts`, контекст или контракты слоев.
- `state-commit` / фиксация изменений → на завершение пользовательской транзакции (не на каждый микро-шаг/тик).

## 3. Без Заглушек и Латок (No Mocks / No Symptom Patches)
- 100% рабочий код. Запрет `// TODO`, моков и неполных фичей.
- Вынужденные компромиссы и архитектурный долг → фиксировать в `docs/techdebt.md` (в коде `// TODO` запрещены).
- Ошибки → устранять первопричину, а не заглушать exceptions.

## 4. Очистка Ресурсов (Cleanup)
- `useEffect` / `onMount` → обязателен возврат cleanup-функций (unsub, event listeners, timers).

## 5. Язык и Документация
- Комменты/JSDoc/чат → строго RU.
- Ознакомиться с `guide.md` модуля перед анализом. Обновление doc-файлов → после выполнения задачи.

## 6. Мёртвый Код (Zero Dead Code)
- Обязательное удаление неиспользуемых импортов, старых интерфейсов и закомментированного кода. Запрет "хвостов".

## 7. Валидация и ACL (Boundary Validation)
- Внешние данные (API, хранилища, файлы, события) → обязательная runtime-валидация схем на границах.
- Anti-Corruption Layer: запрет сырых DTO в UI/компонентах → строго через мапперы (`dtoToDomain`) и fallback-значения.

## 8. Локальная Проверка
- После каждого этапа:
  ```powershell
  npm run lint
  npx tsc --noEmit
  ```
- Ошибки чинить немедленно.
