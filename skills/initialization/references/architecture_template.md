## 🔄 Направленный граф зависимостей (DAG)

1. **Однонаправленный поток**:
   {{DEPENDENCY_GRAPH_RULES}}
2. **Правила импортов**:
   - Запрещены циклические импорты (Circular Dependencies).
   - Запрещены обратные импорты из нижних/чистых слоев в верхние UI/инфраструктурные слои.
   - Импорт соседних слайсов на одном слое допускается только через их публичные контракты `index.ts`.
3. **Принципы Low Coupling & High Cohesion**:
   - **Low Coupling (Минимизация связанности)**:
     - *Закон Деметры (Law of Demeter)*: модуль взаимодействует только с непосредственными зависимостями, запрет транзитивных цепочек `a.b.c.d()`.
     - *Инверсия зависимостей (DIP)*: слои и компоненты зависят от абстракций (`interface`), а не от конкретных реализаций модулей.
     - *Изоляция модулей/слайсов*: 0 неконтролируемых связей между соседями одного слоя; координация через шину событий или фасад контекста.
     - *Инкапсуляция границ*: запрет глубоких импортов (`deep imports`) внутренних файлов модулей в обход экспортов `index.ts`.
     - *Изоляция платформенного окружения*: запрет прямого связывания с глобальными API платформы в обход фасада ядра/контекста.
   - **High Cohesion (Максимизация функциональной связности)**:
     - *Принцип единственной ответственности (SRP)*: каждый файл и модуль имеет одну зону ответственности и одну причину для модификации.
     - *Функциональная связность*: все части фичи/модуля (схема валидации, типы, UI-компонент, контроллеры) локализованы в одной директории.
     - *Анти-God-Object*: запрет монолитных утилит общего назначения (`utils.ts`, `helpers.ts`) и слитных супер-сторов; строгое разделение по узким доменам.

## 🛡️ Валидация и Изоляция (Anti-Corruption Layer - ACL)

1. **Входные границы и Валидация**:
   - Все внешние данные (API, файлы, сокеты, хранилище, плагины) валидируются при получении ({{VALIDATION_STRATEGY}}).
   - Для плагинных архитектур: манифест плагина валидируется на границе ядра (`kernel/schema.ts`), а доменные схемы данных плагина инкапсулируются внутри самого плагина (`plugins/[name]/schema.ts`).
2. **Anti-Corruption Layer (ACL)**:
   - Сырые структуры внешних систем (DTO) не проникают в UI и стейт.
   - Мапперы (DTO → Domain Entity) преобразуют внешние контракты во внутренние модели домена.
   - Безопасные fallbacks при сбоях или неполных внешних данных (fallback-компоненты при сбоях плагинов).
   - Контекст окружения и единое состояние: фасад `getState()` в `PluginContext` (актуальный снимок состояния среды, режимов, параметров и рантайм-ввода) + шина событий `EventBus` ядра вместо прямого доступа плагинов к глобальным платформенным API.
