# Навык Pocket (Изолированное Архитектурное Хранилище)

Навык для создания, каталогизации и безопасного извлечения зашифрованных архивов проекта в изолированной удаленной ветке Git `pocket` (`sozercaniekosmosa/agents-config`) без изменения текущей рабочей ветки и с гарантированным удалением локальных следов архива из Git.

---

## 🔑 Ключевые Принципы

1. **Изоляция Git и Нулевой локальный след (Zero Checkout Risk & Zero Local Footprint)**:
   - Все операции с веткой `pocket` осуществляются через Git Plumbing (`hash-object`, `mktree`, `commit-tree`, `cat-file`, `fetch`, `push`).
   - Текущая рабочая ветка и несохраненные локальные файлы проекта остаются неприкосновенными.
   - После успешного `push` в удаленный репозиторий локальный Git ref `refs/heads/pocket` удаляется (`wipeLocalPocketRef`), исключая хранение архивов в локальном `.git`.
2. **Удаленное защищенное хранилище (Remote Cloud Storage)**:
   - Хранилищем карманов по умолчанию выступает ветка `pocket` центрального репозитория `https://github.com/sozercaniekosmosa/agents-config.git`.
   - Операции `list` и `unpack` обращаются к удаленной ветке через `FETCH_HEAD` без создания локальной постоянной ветки.
3. **Криптографическое сокрытие (Zero Signature & Opaque Storage)**:
   - Данные сжимаются в ZIP и шифруются алгоритмом AES-256-GCM с деривацией ключа scrypt по `POCKET_SECRET_KEY` из `.agents/skills/pocket/.env`.
   - Заголовок и сигнатуры ZIP полностью отсутствуют. Файл сохраняется в хранилище Git без расширения как псевдослучайный бинарный поток.
4. **Безопасная распаковка и автозамена**:
   - Перед извлечением выполняется обязательный предпросмотр всех целевых путей.
   - Извлечение производится по исходным путям с безусловной автозаменой.
   - При коллизиях доступа (блокировка процессами, отсутствие прав записи) сбойные файлы безопасно изолируются в корневой каталог `.pocket/<relative_path>`.
5. **Сохранение структуры каталогов**:
   - Сохраняются как заполненные каталоги, так и пустые папки.

## 🛠 Доступные CLI Команды

```bash
# 1. Вывести нумерованный список всех сохраненных карманов из remote (по умолчанию без аргументов)
node .agents/skills/pocket/scripts/pocket.cjs [list]

# 2. Создать карман из файлов и папок (имя до/после путей или автогенерация, добавляется YY-MM-DD-HH-MM_<name>)
node .agents/skills/pocket/scripts/pocket.cjs create [<name>] <paths...>

# 3. Скачать карман из remote и распаковать в проект с автозаменой (по имени, базовому имени или номеру)
node .agents/skills/pocket/scripts/pocket.cjs unpack <name|index>

# 4. Удалить карман из remote (по имени, базовому имени или номеру)
node .agents/skills/pocket/scripts/pocket.cjs delete <name|index>
```

## 📋 Порядок Действий Агента

1. **Просмотр каталога / Вызов без параметров ("список карманов" / "покажи карманы" / `/pocket` без аргументов)**:
   - При вызове `/pocket` без параметров агент **НЕМЕДЛЕННО** запускает команду `node .agents/skills/pocket/scripts/pocket.cjs` (или `list`) без лишних уточняющих вопросов.
   - Выводит нумерованный список сохраненных карманов (имя с датой-временем `YY-MM-DD-HH-MM_<name>`, размер, хэш, дата).

2. **Создание кармана ("сохрани в карман ...")**:
   - Агент парсит имя кармана и пути к файлам/папкам из текста сообщения:
     - Имя кармана может передаваться в чате **ДО** или **ПОСЛЕ** путей к файлам.
     - Если имя не передано явно, агент (или CLI) придумывает краткое смысловое имя сам (по первому файлу/папке или контексту).
     - К имени кармана обязательно добавляется дата-время перед именем в формате `YY-MM-DD-HH-MM_<name>` без квадратных скобок (например, `26-10-19-15-35_docs`).
   - Запускает команду `create [<name>] <paths...>`.
   - Кратко сообщает статус, итоговое имя кармана, хэш коммита, размер зашифрованного архива и подтверждение удаления локального ref.

3. **Восстановление кармана ("достань из кармана <name>" / "распакуй <name>")**:
   - Агент запускает команду `unpack <name>` (поддерживается точное имя с таймстемпом, базовое имя с автопоиском последней версии, либо порядковый номер кармана из списка).
   - Анализирует вывод предпросмотра и список восстановленных файлов.
   - При наличии коллизий сообщает пути файлов, перемещенных в `.pocket/`.
   - **Финальный обязательный вопрос**: После завершения распаковки агент **ОБЯЗАТЕЛЬНО** задает пользователю вопрос: *"Удалить карман `<name>` в удаленном репозитории? (Да / Нет)"*. При утвердительном ответе («Да», «Удали», «Confirm») запускает команду `delete <name|index>` и подтверждает удаление.

4. **Удаление кармана ("удали карман <name>" / "удали pocket <name>")**:
   - Агент запускает команду `delete <name|index>`.
   - Сообщает статус удаления, имя удаленного кармана и хэш коммита в remote.

## ⚙️ Конфигурация

- Шаблон: `.agents/skills/pocket/_.env`
- Локальный секрет: `.agents/skills/pocket/.env`
- Переменные окружения:
  - `POCKET_SECRET_KEY`: ключ шифрования AES-256-GCM.
  - `POCKET_REMOTE_URL`: URL удаленного репозитория (по умолчанию `https://github.com/sozercaniekosmosa/agents-config.git`).
- Файл `.env` защищен локальным `.gitignore` и не попадает в систему контроля версий.

## 🔄 Петля Эволюции Навыка (Feedback Loop)

1. **Контроль деградации**: при модификации логики Git Plumbing или сетевого взаимодействия проводить E2E верификацию (`create` → `list` → `unpack`).
2. **Zero Local Footprint**: контролировать, что после операций `create`, `list`, `unpack` локальный ref `refs/heads/pocket` отсутствует.
3. **Синхронизация контрактов**: при расширении параметров команд `pocket` актуализировать спецификацию в данном файле и регистрировать обновления в `.agents/evolution.json`.
