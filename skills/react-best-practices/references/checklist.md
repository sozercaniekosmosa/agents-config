# Клиентский перформанс — чек-лист аудита (read-only)

Назначение: быстрый статический проход по React-коду в рамках `/check` (проектные стандарты из `docs/project-rules.md`, раздел Quality Gates).
Формат вывода: `path/file.tsx:Lx → [маркер]`, статус `[!]`.
Маркер — повод для проверки, не приговор: подтверждать по коду/профилю.

## Маркеры

1. Derived state в эффекте: `useEffect(() => setX(...), [...])` → вычислять в рендере.
2. Компонент объявлен внутри компонента → вынести на модульный уровень.
3. `useState(expensive())` без ленивого инициализатора → `useState(() => ...)`.
4. `memo`-компонент получает инлайн-объект/массив/функцию → стабильные ссылки или модульные константы.
5. Zustand: подписка на весь store или селектор, создающий новый объект, без `useShallow` → точечные селекторы.
6. TanStack Query: тяжёлые трансформации в теле компонента без `select`; `staleTime: 0` у статичных данных.
7. Независимые запросы выполняются последовательными `await` → `Promise.all`/`useQueries`/prefetch.
8. Тяжёлые библиотеки (графики, графы, таблицы) импортированы статически в маршруте → `React.lazy` + `Suspense`.
9. Маршруты не разбиты code-splitting → ленивые маршруты роутера.
10. Списки >100 строк без виртуализации/`content-visibility`.
11. Глобальные `scroll`/`touch` listeners без `passive: true`.
12. `localStorage` читается в рендере/цикле → кэш и инициализация.
13. `useMemo`/`useCallback` для примитивов без измеренной выгоды → удалить (Zero Dead Code).
14. Несколько `filter()/map()` по одному массиву → объединить в проход.
15. `sort()` мутирует проп/состояние → `toSorted()` или копия.
16. Ленивый компонент без `Suspense` fallback → добавить fallback.

## Ограничения

- Только чтение: авто-фиксы запрещены (это зона `/resolve`).
- Не предлагать deep-import в обход FSD public API.
- Не предлагать новые зависимости.
- Не выдавать перф-находки за архитектурные нарушения: статус `[!]`, не `[✗]`.

## Автоматизация

- Минимум (4 класса маркеров: lazy без Suspense, non-passive touch/wheel, дорогой init useState, тяжёлый импорт в точке входа): `node .agents/skills/react-best-practices/scripts/check-perf.cjs --src src`.
- Перед коммитом: `--staged`; блокировка при маркерах: `--strict`.
- Скрипт не заменяет полный чек-лист (16 маркеров) — остальное вручную или через `/check`.
