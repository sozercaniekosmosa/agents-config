# Контракт навыка «Пресеты-заготовки карточки»

Справочник для правок: что где лежит, что публично, что нельзя ломать.
Обновлять при смене контракта; протокол, автономия и гейты — `../SKILL.md`.

## 2. Публичный контракт

`CardPreset`:

| Поле | Обязательно | Смысл |
| --- | --- | --- |
| `id` | да | стабильный kebab-id, уникален внутри набора |
| `label` | да | текст, который добавляется в карточку |
| `description` | нет | короткое пояснение в списке и tooltip |
| `value` | да | смысл заготовки/подсказка в tooltip, в карточку не пишется |
| `group` | нет | раздел палитры; пресеты группы идут подряд |
| `tags` | нет | скрытые ключи поиска, точная основа |

`CardPresetCollection`: `{ fieldId, fieldTitle, presets }` — `fieldId` это id поля каталога (`gen_genre`), `fieldTitle` — его заголовок («Жанр»).

`CARD_PRESET_COLLECTIONS` — единственный реестр; новая карточка с пресетами добавляет ровно одну запись, UI не меняется.

`resolveCardPresets({ id, title })`:
- нормализация `trim().toLowerCase()`;
- совпадение по `id`: равенство `fieldId` или префикс `<fieldId>_` (id узла вида `gen_genre_<projectId>`);
- совпадение по `title`: точное равенство нормализованному `fieldTitle` (legacy-узлы);
- нет совпадения → `[]`; карточка без пресетов не показывает кнопку.

Текущие данные: шесть наборов, 380 пресетов.

Набор «Эпоха»: `value` — цельный текст эпохи (быт, техника, социальный уклад), группы идут по исторической хронологии, внутри группы пресеты упорядочены по времени. Набор «Жанр и атмосфера» объединяет два верхних раздела палитры; настроенческий пресет добавляет прилагательное, `value` поясняет его проявление в тексте.

## 3. Применение в карточку

- В текст попадают только `label` выбранных пресетов.
- Уже присутствующие названия не дублируются: проверка `existingLower.includes(label.toLowerCase())`.
- Склейка: `"${base}, ${labels.join(", ")}"`, где `base` — текущий текст без хвостовых `,` и пробелов; пустая карточка получает просто список.
- Запись идёт через `useSectionCardAi.applyContent`: отменяет отложенное сохранение, ставит значение, пересчитывает высоту, сохраняет, показывает «Сохранено».
- Палитра закрывается до записи; режим правки восстанавливается, если палитру открыли из него.

## 4. Поиск

- Нормализация: нижний регистр, `ё → е`; разбиение по не-буквам.
- Грубая основа: срез русских окончаний, слово короче 4 символов не режется.
- `label`: совпадение по началу основы при любой длине запроса; при основе ≥ 5 символов допускается вхождение.
- `description`: участвует только с основы ≥ 3 символов — короткий ввод не должен поднимать карточки по словам из подсказки.
- Скрытые `tags`: только точная основа — «ужасы» находит все хорроры с тегом, «при» не цепляет фэнтези с тегом «приключения».
- Запрос из 1–2 символов матчит только названия: ни теги, ни описания.
- Многотокенный запрос требует совпадения всех токенов.
- Счётчик палитры — `найдено / всего`, пустой результат даёт «Сбросить поиск».

## 5. UI палитры и карточки

- Палитра: `Modal size="5xl"` (1024 px), высота 86vh, сетка 2/3/4 колонки, компактные ряды (`px-1.5 py-0.5`), без рамок и фонов у рядов.
- Чекбокс скрыт (`peer sr-only`); невыбранный — прозрачный, выбранный — только зелёная галочка.
- Группа: заголовок + счётчик, кнопка «выбрать группу»/«снять группу»; поиск закреплён сверху.
- Футер: «Выбрано N», список выбранных, «Снять выбор», «Отмена», «Примерить» (неактивна при 0).
- Заголовок палитры — «Пресеты-заготовки», кнопка — «Пресеты»: подписи нейтральные, так как наборы не только жанровые.
- Карточка: кнопка «Пресеты» только когда набор найден; других входов нет (Ctrl+Space удалён).
- Пока палитра открыта, `presetOpenRef` запрещает сохранение устаревшего текста по blur.

## 6. Рецепты расширения

1. **Набор для нового поля**: `presets/<domain>/<group>.ts` на группу → баррель `<domain>/index.ts` → агрегатор `<domain>Presets.ts` → запись в `CARD_PRESET_COLLECTIONS` → `presets-lint` → `track --update`.
2. **Новая группа в существующем наборе**: файл группы → экспорт в барреле → место в агрегаторе (порядок = порядок разделов палитры) → линтер.
3. **Нежанровый набор**: подписи палитры и кнопки нейтральные («Пресеты-заготовки», «Пресеты»); линтер падает, если вернуть в `SectionCardPresetPalette.tsx`/`SectionCardToolbar.tsx` строки «Жанровые пресеты» или «выбрать жанры» при нежанровом наборе в реестре.
4. **Новое поле каталога**: `src/shared/templates/fields/*.ts` → `id`, `title`; id узла карточки формируется как `<fieldId>_<projectId>`, поэтому набор подхватывается без UI-правок.
5. **Legacy-узлы без узнаваемого id**: набор находится по точному `fieldTitle`; подстроки не работают.
6. **Изменение семантики поиска**: правка `presetSearch.ts` + инвариант 5 в `SKILL.md` + ручная проверка запросов («при», «ужасы», «детектив», «сказка»).

## 7. Ловушки

- Тег по префиксу цепляет лишние карточки: «при» находил фэнтези из-за тега «приключения» → теги только по точной основе.
- `value` ожидают в карточке, но вставляется `label`: `value` — смысл заготовки и tooltip.
- Дубликат `id` ломает `Set` выбора и React-key — линтер ловит первым.
- Запятая внутри `label` рвёт список «через запятую».
- `resolveCardPresets` не ищет по подстроке title: только точное совпадение.
- Добавление файла в базу без `track --update` даёт дрейф — это сигнал синхронизации.
- `npm run build` на Windows: системный TEMP даёт `Access is denied` у esbuild → `$env:TEMP`/`$env:TMP` внутри репозитория.
- Пустой набор в реестре даёт кнопку без данных: линтер запрещает пустой `presets`.
- Жанровая подпись в общей палитре врёт на нежанровом наборе: подписи нейтральные, линтер держит это правило.

## 8. Definition of done

- `presets-lint` зелёный: поля существуют, id/label уникальны, `value`/`group` заполнены, подписи нейтральны для нежанровых наборов.
- `track.cjs --check` без дрейфа, `forge check` зелёный, `npx tsc -b`, `npm run arch:check`, `npm run build`.
- Палитра проверена в браузере: поиск, выбор групп, «Примерить», отсутствие дублей, восстановление режима правки.
- `CHANGELOG.md` навыка и лог observer получили строку; гайды затронутых модулей обновлены, если поведение изменилось.
