# 📡 Потоки Данных CEMIS (REST & SignalR)

## 1. Единый хук получения данных: `useCemisData`
Файл: `src/entities/cemis/lib/use-cemis-data.ts`
Отвечает за агрегацию, подписку и выдачу метрик для UI.

### Механизм работы (Приоритеты):
- Сбор всех запрошенных свойств (`allPropertyIds`).
- Первичный срез: REST-запрос `fetchTagLatest` по `propertyIds` и `dateRange`.
- Реалтайм-подписка: SignalR хук `useTagRealtime` (`joinTags(allPropertyIds)`).
- **Приоритет вывода**: При разрешении значения метод `getValue` сначала ищет ключ в `realtimeMap` (SignalR), и только при отсутствии берет из `tagValuesMap` (REST).

### Константы состояний:
- `CEMIS_LOADING_PROP_VALUE` = `...` (данные загружаются или еще не поступили).
- `CEMIS_INVALID_PROP_VALUE` = `!!!` (ошибка получения данных или свойство не найдено).

## 2. Шаблоны свойств и маппинг
Файл: `src/entities/cemis/api/cemis-property-templates.ts`
- Содержит константы `GTPP_TEMPLATES` и `PUMPS_TEMPLATES`.
- Связывание метрик в UI со значениями из БД происходит через **Alias** (элиасы, например `actualPower`, `waterFlow`).
- **Элиасы КПД Насосов**:
  - `efficiencyDayPercent` — КПД за день в процентах (`kpdDayFact`).
  - `efficiencyMonthPercent` — КПД за 30 дней в процентах (`kpd30dFact`).
  - `efficiencyStertMonthPercent` / `efficiencyStartMonthPercent` — КПД с начала месяца в процентах (`kpdMonthStartFact`).
  - Старые GUID сохранены с суффиксом `Alt` для обратной совместимости при поэтапной миграции бэкенда.
- *Критическое правило*: Использование legacy GUID'ов устарело и будет удалено. Запрещено добавлять новые захардкоженные GUID'ы. Всегда использовать алиасы.

## 3. Специфика графиков (Трендов) и маппинг
- **Общее правило для плашек (StatCards)**: В каждом тренде справа от графика располагаются плашки (от 2 до 4 шт.), которые показывают, какие перья выводятся в тренде. Значение в этих плашках должно строго отображать **последнее значение пера** в выбранном диапазоне/дате (получаемое из массива данных тренда), а не скалярное значение через `getValue`.
- **Каскадное разрешение элиасов (Candidate Aliases)**:
  - Для каждого параметра задается группа кандидатных элиасов (`PARAM_CANDIDATE_ALIASES` / `PUMP_PARAM_CANDIDATE_ALIASES`), включающая базовый ключ, периодические варианты (`Day`, `Month`, `StartMonth`) и альтернативные наименования.
  - Поиск точек выполняется каскадно: сначала по `unitTrendData`, при отсутствии — по `overallTrendData` (для параметров станции/агрегатов).
  - При наличии одиночной точки на графике задается `pointRadius: 4` (вместо 0), чтобы точка не скрывалась из-за отсутствия отрезка линии.
